# Поиск в Tor с помощью HTTP-прокси

## Описание
Этот скрипт `tor_search_http.py` позволяет выполнять поиск в сети через HTTP-прокси Tor. В отличие от предыдущей версии, где использовался SOCKS-прокси, эта версия работает через HTTP-прокси (обычно Privoxy в связке с Tor), что делает соединение более стабильным на некоторых платформах, особенно на Windows.

## Особенности

- **Использование HTTP-прокси** (по умолчанию 127.0.0.1:8118) для соединения с Tor
- Поиск через различные поисковые системы (Ahmia, DarkSearch.io, Torgle)
- Поиск на указанных .onion сайтах с обходом страниц
- Резервный поиск через Google, если поиск через указанные системы не дал результатов
- Сохранение результатов в JSON файл
- Вывод контекста упоминания ключевых слов

## Требования

- Python 3.7 или выше
- Tor Browser или сервис Tor, запущенный на компьютере
- Privoxy (для HTTP-прокси) или аналогичный HTTP-прокси для Tor
- Зависимости из файла requirements.txt

## Установка зависимостей

pip install requests beautifulsoup4 PySocks

## Настройка HTTP-прокси для Tor

### Windows
1. Установите Tor Browser с официального сайта torproject.org
2. Установите Privoxy с официального сайта privoxy.org
3. Настройте Privoxy на работу с Tor:
   - Откройте файл config.txt в директории установки Privoxy
   - Добавьте строку: `forward-socks5 / 127.0.0.1:9050 .`
   - Перезапустите службу Privoxy

По умолчанию Privoxy использует порт 8118 для HTTP-прокси.

### Linux
```bash
sudo apt-get install tor privoxy
sudo nano /etc/privoxy/config
# Добавьте строку:
# forward-socks5 / 127.0.0.1:9050 .
sudo systemctl restart privoxy
```

## Использование

### Интерактивный режим

```bash
python tor_search_http.py
```

Скрипт запросит:
1. Поисковый запрос
2. Список поисковых систем (опционально)
3. Список конкретных сайтов для поиска (опционально)
4. HTTP-прокси (опционально, по умолчанию 127.0.0.1:8118)

### Параметры командной строки

```bash
python tor_search_http.py --query "ваш запрос" --engines ahmia,darksearchio --sites "site1.onion,site2.onion" --proxy 127.0.0.1:8118
```

Доступные параметры:
- `--query` или `-q`: Поисковый запрос
- `--engines` или `-e`: Поисковые системы через запятую (ahmia,darksearchio,torgle)
- `--sites` или `-s`: Конкретные сайты для поиска через запятую
- `--depth` или `-d`: Глубина поиска (количество страниц для обхода каждого сайта)
- `--maxresults` или `-m`: Максимальное количество результатов от каждой поисковой системы
- `--proxy` или `-p`: HTTP-прокси в формате host:port

## Поддерживаемые поисковые системы

- **Ahmia**: Популярный поисковик для скрытых сервисов (ahmia.fi)
- **DarkSearch.io**: Поисковая система для темной сети
- **Torgle**: Альтернативный поисковик для .onion сайтов

## Важно!

- В случае проблем с подключением скрипт попытается использовать обычное соединение без анонимности
- Если используете обычное соединение, ваши запросы не будут анонимными
- Всегда проверяйте, что Tor и Privoxy запущены перед использованием скрипта

## Примеры

```bash
# Поиск по ключевым словам через все поддерживаемые поисковые системы
python tor_search_http.py --query "bitcoin mixer"

# Поиск только через Ahmia и DarkSearch
python tor_search_http.py --query "security" --engines ahmia,darksearchio

# Поиск на конкретных сайтах с глубиной обхода 3 страницы
python tor_search_http.py --query "privacy" --sites "3g2upl4pq6kufc4m.onion,duckduckgogg42xjoc72x3sjasowoarfbgcmvfimaftt6twagswzczad.onion" --depth 3

# Использование альтернативного прокси
python tor_search_http.py --query "anonymous" --proxy 127.0.0.1:8080
```
