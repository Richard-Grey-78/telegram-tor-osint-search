# Расширенный поиск групп в Telegram

Этот скрипт позволяет выполнять расширенный поиск групп в Telegram по ключевым словам, в отличие от стандартного поиска, который часто выдает мало результатов.

## Возможности

- Поиск групп по ключевым словам в названиях групп
- Поиск групп по ключевым словам в описаниях групп
- Поиск групп по ключевым словам в сообщениях (для открытых групп)
- Сохранение результатов в JSON-файл
- Отображение даты создания группы и количества участников
- Сохранение сессии Telegram для последующих запусков

## Методы поиска

Скрипт использует три разных метода поиска для максимального охвата:
1. Поиск среди диалогов пользователя
2. Поиск через контакты Telegram
3. Локальный поиск по сообщениям в доступных чатах

## Использование

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Создайте файл .env на основе .env.example и укажите свои данные API Telegram

3. Запустите скрипт:
   ```
   python telegram_search.py
   ```

4. При первом запуске вам будет предложено авторизоваться в Telegram (введите код подтверждения из сообщения)

5. Введите ключевые слова для поиска, разделяя их запятыми или заключая фразы в кавычки

6. Результаты будут выведены в консоль и сохранены в файл JSON

## Примечания

- Скрипт использует Telethon API для взаимодействия с Telegram
- Для работы требуются правильные API_ID и API_HASH в файле .env
- Сессия сохраняется между запусками, так что вам не придется авторизоваться каждый раз
- Поиск по сообщениям работает только для чатов, в которых вы состоите
