# Поиск в сети Tor по ключевым словам

Скрипт для поиска информации в сети Tor (даркнет) по ключевым словам. Инструмент использует несколько поисковых систем даркнета и может осуществлять поиск по отдельным .onion сайтам.

## Возможности

- Поиск через популярные поисковые системы даркнета (Ahmia, Torch, NotEvil и др.)
- Прямой поиск на конкретных .onion сайтах с обходом внутренних страниц
- Смена IP-адреса между запросами для анонимности
- Сохранение результатов в JSON-файл с подробной информацией
- Вывод контекста упоминания ключевых слов на найденных страницах

## Требования

Для работы скрипта необходимо:

1. **Tor Browser** или **Tor service** запущенный на порту 9050
2. Python 3.7 или выше
3. Установленные зависимости (см. файл requirements.txt)

## Установка

1. Убедитесь, что у вас установлен и запущен Tor:
   ```bash
   # Для Linux:
   sudo apt install tor
   sudo systemctl start tor

   # Для macOS:
   brew install tor
   brew services start tor
   ```

   Или просто запустите Tor Browser и оставьте его открытым.

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

### Интерактивный режим

Просто запустите скрипт без параметров:

```bash
python tor_search.py
```

Вам будет предложено ввести поисковый запрос и другие параметры поиска.

### Командная строка с параметрами

```bash
python tor_search.py --query "ваш запрос" --engines ahmia,torch --sites "example.onion,another.onion" --depth 3 --renew-ip
```

### Параметры командной строки

- `--query`, `-q`: Поисковый запрос
- `--engines`, `-e`: Поисковые системы через запятую (по умолчанию: ahmia,darksearchio)
- `--sites`, `-s`: Конкретные .onion сайты для поиска, через запятую
- `--depth`, `-d`: Глубина поиска по сайтам (количество страниц для обхода, по умолчанию: 2)
- `--maxresults`, `-m`: Максимальное количество результатов от каждой поисковой системы (по умолчанию: 10)
- `--renew-ip`, `-r`: Обновлять IP-адрес Tor между запросами

## Поддерживаемые поисковые системы

- `ahmia`: Ahmia.fi - популярная поисковая система для Tor
- `torch`: Torch - один из старейших поисковиков даркнета
- `notevil`: Not Evil - поисковая система для скрытых сервисов
- `darksearchio`: DarkSearch.io - поисковая система для даркнета
- `candle`: Candle - альтернативная поисковая система

## Безопасность и анонимность

- Скрипт работает через SOCKS5-прокси Tor, обеспечивая базовую анонимность
- Опция `--renew-ip` позволяет менять цепочку Tor между запросами
- Используются случайные User-Agent для запросов

## Примечания

- Поиск в даркнете может занимать значительное время из-за медленных соединений
- Некоторые поисковые системы могут быть недоступны в определенное время
- Для доступа к контроллеру Tor (для смены IP) может потребоваться настроить пароль в файле torrc
